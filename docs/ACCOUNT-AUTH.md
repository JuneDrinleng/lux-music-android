# 资料、LX 连接与切换

2026-11-14。首版本机模式 + 原版 LX；Lux 密码登录/注册/refresh 后置。当前决策见 [计划](../plan.md)，历史 Lux 方案见 [归档](future/LUX-ACCOUNT-AUTH.md)。本文件定义行为和数据边界，连接页补充基准见 [设计约定](design/README.md)。

## 单一状态与身份

core:api 的 ProfileSession 是唯一公共资料状态端口，data 内一个 ProfileStore 实现；不并存 AccountStore、SessionManager 和协调器三套全局状态。

| 概念 | 定义 |
| --- | --- |
| ProfileId | 安装内生成的稳定资料标识，独立于 URL、连接码、clientId |
| 本机资料 | 独立业务库，无认证要求 |
| LX 资料 | 关联本地 bindingId、serverId、规范化 endpoint 和设备凭据引用 |
| 认证 | 无需认证 / 可用 / 需要重新授权；不与网络在线布尔量混合 |
| 同步 | 断开、连接、协商、初始同步、冲突、模块就绪、失败 |

LX /ah 返回 clientId/key/serverName，没有稳定远端用户 ID。serverId 只识别服务，多个用户可以共用一个 serverId；clientId 是设备授权，不当作可跨重授权稳定的远端用户 ID。改连接码默认新建绑定。首版不提供隐式重绑或自动合并。

## 持久化与授权边界

一个目录 Room 库保存元数据、活动 ProfileId 和密文引用；每个 ProfileId 一个业务库/文件根目录，用不可碰撞标识编码路径，不拼接用户名或连接码。每次只打开目录和活动资料所需库。

clientId/key 使用平台 Keystore 的 AES-GCM 密钥加密，随机 nonce，AAD 绑定 ProfileId、记录类型和 schemaVersion；不退回明文。代码、导航、日志、截图和 saved state 不含连接码或设备 key。连接码只在当前认证请求内存使用。自动备份排除 vault/密钥关联记录；Keystore 失效标记重新授权，保留业务资料。

连接地址保留反向代理 base path，规范化 scheme/host 不破坏大小写敏感路径。不因 TLS 错误自动切 HTTP或关闭校验。默认 HTTPS/WSS；确需内网 HTTP 时在平台配置与交互中显式确认，不静默放开全部传输。

## 添加连接与重新授权

本机使用可直接进入音乐页面。添加连接依次输入服务器、检查 hello/id、输入连接码、认证、保存凭据、进入该资料的初次同步。设备名可编辑但有默认值，wire 平台值仍用上游要求的 lx_music_mobile。

地址或 TLS 错误显示在服务器步骤；连接码认证失败留在认证步骤；限流、断网、服务器错误不冒充“密码过期”。输入改变后旧探测结果因 generation 失效，不覆盖新输入。

已保存连接先用设备密钥重认证；拒绝后标记需重新授权并允许继续离线。重新输入连接码默认创建新绑定，避免误把另一个远端用户接到旧资料。首版不调用 Lux REST，也不探测 server-info 作为 LX 前置条件。

## 切换及恢复

ProfileStore 串行处理：只读准备目标 → 停止旧同步/请求/播放并保存旧队列快照 → 代际屏障 → 打开目标库 → 目录事务提交活动指针 → 绑定目标状态流与同步。提交前失败仍是旧资料；提交后网络失败停留目标离线。目标队列不自动续播。

每个任务捕获 ProfileId、generation 和库句柄，事务提交前复核；不能在返回时查 currentDatabase 后写入。进程重启从已提交活动指针恢复，不需要跨库多阶段 journal。旧回调无法写入新资料；切换本身不移动歌曲、不复制文件、不远端退出。

## 断开、退出、删除

| 操作 | 行为 |
| --- | --- |
| 断开同步 | 停止 WS/同步，保留设备授权与资料，可重连 |
| 退出连接 | 停止任务、清本机授权，保留资料时仍可离线；说明远端授权撤销未确认 |
| 删除资料 | 明确确认范围，停止所属任务，再删除该资料库、文件、密文和目录记录 |

原版 LX 没有 Lux logout/refresh/session 管理 API，不能调用不存在的接口或假称服务端 key 已删除。若需远端撤销提示联系服务器管理员。首版无撤销租约、无五账号上限、无 RN 私有数据导入、无跨资料自动上传。

## 验收

覆盖同服务器多个连接隔离、换码新建绑定、离线切换、A→B→C、迟到消息、目录提交前后杀进程、开库失败、密文写入失败、Keystore 失效和退出/删除边界。需要真实 Room 与协议 fixtures，不能仅 mock 按钮成功。
