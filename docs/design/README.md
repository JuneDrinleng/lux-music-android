# 设计基准与 LX 连接补充

现有 [HTML](../../ui/index.html) 与 [design.md](../../design.md) 已构成基准，沿用米白/苔绿视觉与 MingCute 资源。旧的“尚无原型、重新选风格”描述失效。

音乐页面、布局、层级、资源、状态、动效、返回栈继续严格 1:1。本阶段仅确定 LX 新交互范围，不修改 HTML 或宣称设计已签字。

## 待补充并审阅的连接状态

| 页面/操作 | 必须覆盖 |
| --- | --- |
| 首次使用 | 本机使用、添加同步连接；不出现 Lux 注册/登录 |
| 服务器 | 完整地址/子路径、检查中、地址/TLS/网络/协议错误、更换地址 |
| 认证 | 连接码、默认设备名、防重复提交、取消、限流/拒绝；不持久化敏感输入 |
| 初次同步 | 本机/服务器资料说明、合并、两个覆盖方向、取消；覆盖不静默记忆 |
| 资料管理 | 本机与连接列表、切换中/失败/离线、需重新授权 |
| 退出/删除 | 断开、退出与删除资料的影响范围分别表达；远端撤销未确认 |

沿用现有设计参数补原型和可执行状态，经 June 审阅形成验收基准。骨架、协议和存储验证可先推进；相关可见页面实现遵循审阅后的补充基准。UX 语义见 [资料规范](../ACCOUNT-AUTH.md)。
